Postman Test Documentation for Order APIs
========================================

**Lưu ý chung:**

*   **Base URL**: Địa chỉ gốc của API (ví dụ: `http://localhost:3000`)
*   **Authentication**: Hầu hết các endpoint Order yêu cầu người dùng phải đăng nhập. Giả định bạn đang sử dụng JWT được lưu trong cookie tên là `token`. Bạn cần đăng nhập trước qua API `/api/auth/login`, sau đó Postman sẽ tự động gửi cookie `token` trong các request tiếp theo. Nếu bạn dùng Authorization header, hãy thay thế `Cookie` bằng `Authorization: Bearer YOUR_JWT_TOKEN`.
*   **Admin Role**: Một số endpoint yêu cầu quyền Admin. Đảm bảo tài khoản bạn dùng để đăng nhập có role 'admin'.
*   **Headers**: Đối với các request `POST` và `PUT`, bạn cần thêm Header `Content-Type` với giá trị `application/json`.

**1. Tạo Đơn Hàng Mới**

*   **Method**: `POST`
*   **URL**: `{{BASE_URL}}/api/orders`
*   **Authentication**: Yêu cầu đăng nhập (Người dùng bất kỳ).
*   **Headers**:
    *   `Content-Type`: `application/json`
    *   `Cookie`: `token=YOUR_JWT_TOKEN`
*   **Body** (raw - JSON):
    *   Cung cấp thông tin chi tiết đơn hàng và danh sách các `items`.
    *   `menuItemId` cần được thay bằng ID thực tế của các MenuItem trong database của bạn.
    *   **Quan trọng**: `unitPrice` trong `items` hiện đang được lấy từ request (theo code tạm thời trong service). **Bạn nên bỏ trường `unitPrice` khỏi request body này** và hoàn thiện logic trong `order.service.js` để tự động lấy giá từ `MenuItem` trong database khi hàm `createOrder` được gọi.
    ```json
    {
      "orderDate": "2024-08-16", // Ngày đặt hàng
      "orderTime": "19:00",      // Giờ đặt hàng
      "customerName": "Nguyễn Văn A", // Tên khách hàng
      "phoneNumber": "0912345678",  // Số điện thoại
      "numberOfGuests": 5,          // Số lượng khách
      "eventType": "Liên hoan công ty", // Loại sự kiện
      "specialRequests": "Xuất hóa đơn đỏ.", // Yêu cầu đặc biệt (tùy chọn)
      "items": [ // Danh sách món ăn
        {
          "menuItemId": "ID_MON_AN_1", // <-- Thay bằng ID MenuItem thật
          "quantity": 3
          // "unitPrice": 180000 // Bỏ dòng này đi khi service đã lấy giá từ DB
        },
        {
          "menuItemId": "ID_MON_AN_2", // <-- Thay bằng ID MenuItem thật
          "quantity": 2
          // "unitPrice": 220000 // Bỏ dòng này đi khi service đã lấy giá từ DB
        }
      ]
    }
    ```
*   **Success Response (201 Created)**:
    ```json
    {
      "status": "success",
      "message": "Đơn hàng đã được tạo thành công.",
      "data": {
        // Thông tin chi tiết của đơn hàng vừa tạo (order object)
        "_id": "...",
        "userId": "...",
        "orderCode": "...",
        "totalAmount": ..., // Tổng tiền được tính bởi server
        "orderStatus": "Đang chờ duyệt",
        "paymentStatus": "Chưa thanh toán",
        // ... các trường khác ...
        "createdAt": "...",
        "updatedAt": "..."
      }
    }
    ```
*   **Error Responses**:
    *   `400 Bad Request`: Thiếu trường bắt buộc, `items` rỗng, số lượng/đơn giá không hợp lệ, MenuItem không tồn tại (nếu đã implement kiểm tra).
    *   `401 Unauthorized`: Chưa đăng nhập.
    *   `500 Internal Server Error`: Lỗi server khi xử lý.

**2. Lấy Danh Sách Đơn Hàng Của Tôi**

*   **Method**: `GET`
*   **URL**: `{{BASE_URL}}/api/orders/my-orders`
*   **Authentication**: Yêu cầu đăng nhập (Người dùng bất kỳ).
*   **Headers**:
    *   `Cookie`: `token=YOUR_JWT_TOKEN`
*   **Query Parameters** (Tùy chọn):
    *   `page`: Số trang (mặc định: 1).
    *   `limit`: Số lượng kết quả mỗi trang (mặc định: 10).
    *   `status`: Lọc theo trạng thái đơn hàng (vd: `Đang chờ duyệt`, `Đã xác nhận`, `Đã hủy`, `Hoàn thành`). Bỏ qua để lấy tất cả.
    *   `sortBy`: Trường để sắp xếp (vd: `createdAt`, `totalAmount`, `orderDate`). Mặc định: `createdAt`.
    *   `sortOrder`: Thứ tự sắp xếp (`asc` hoặc `desc`). Mặc định: `desc`.
*   **Example URL**: `{{BASE_URL}}/api/orders/my-orders?limit=5&status=Đang chờ duyệt&sortBy=orderDate&sortOrder=asc`
*   **Success Response (200 OK)**:
    ```json
    {
      "status": "success",
      "results": 2, // Số lượng đơn hàng trong trang này
      "data": {
        "orders": [
          { /* Order object 1 */ },
          { /* Order object 2 */ }
        ],
        "totalCount": 15, // Tổng số đơn hàng của user khớp filter
        "currentPage": 1,
        "totalPages": 3
      }
    }
    ```
*   **Error Responses**:
    *   `401 Unauthorized`: Chưa đăng nhập.
    *   `500 Internal Server Error`.

**3. Lấy Chi Tiết Đơn Hàng**

*   **Method**: `GET`
*   **URL**: `{{BASE_URL}}/api/orders/:orderId`
*   **Authentication**: Yêu cầu đăng nhập (Chủ đơn hàng hoặc Admin).
*   **Headers**:
    *   `Cookie`: `token=YOUR_JWT_TOKEN`
*   **URL Parameters**:
    *   `:orderId`: ID của đơn hàng cần xem.
*   **Example URL**: `{{BASE_URL}}/api/orders/60d5f0a8b48f4f001f8e4d7c` (Thay ID bằng ID thật)
*   **Success Response (200 OK)**:
    ```json
    {
      "status": "success",
      "data": {
        "order": { /* Thông tin chi tiết đơn hàng (order object) */ },
        "items": [ /* Danh sách các món trong đơn hàng (orderItem objects) */ ]
      }
    }
    ```
*   **Error Responses**:
    *   `401 Unauthorized`: Chưa đăng nhập.
    *   `403 Forbidden`: Không phải chủ đơn hàng và không phải Admin.
    *   `404 Not Found`: Không tìm thấy đơn hàng với ID cung cấp.
    *   `500 Internal Server Error`.

**4. Cập Nhật Trạng Thái Đơn Hàng (Admin)**

*   **Method**: `PUT`
*   **URL**: `{{BASE_URL}}/api/orders/:orderId/status`
*   **Authentication**: Yêu cầu đăng nhập (Chỉ Admin).
*   **Headers**:
    *   `Content-Type`: `application/json`
    *   `Cookie`: `token=YOUR_JWT_TOKEN_ADMIN`
*   **URL Parameters**:
    *   `:orderId`: ID của đơn hàng cần cập nhật.
*   **Body** (raw - JSON):
    *   Cung cấp trạng thái mới. Các giá trị hợp lệ: `Đang chờ duyệt`, `Đã xác nhận`, `Đã hủy`, `Hoàn thành`.
    ```json
    {
      "status": "Đã xác nhận"
    }
    ```
*   **Success Response (200 OK)**:
    ```json
    {
      "status": "success",
      "message": "Cập nhật trạng thái đơn hàng thành công.",
      "data": { /* Thông tin đơn hàng đã được cập nhật (order object) */ }
    }
    ```
*   **Error Responses**:
    *   `400 Bad Request`: Trạng thái cung cấp không hợp lệ.
    *   `401 Unauthorized`: Chưa đăng nhập.
    *   `403 Forbidden`: Không phải Admin.
    *   `404 Not Found`: Không tìm thấy đơn hàng.
    *   `500 Internal Server Error`.

---

**5. Hủy Đơn Hàng**

*   **Method**: `PUT`
*   **URL**: `{{BASE_URL}}/api/orders/:orderId/cancel`
*   **Authentication**: Yêu cầu đăng nhập (Chủ đơn hàng hoặc Admin).
*   **Headers**:
    *   `Cookie`: `token=YOUR_JWT_TOKEN`
*   **URL Parameters**:
    *   `:orderId`: ID của đơn hàng cần hủy.
*   **Body**: (Không cần gửi body)
*   **Success Response (200 OK)**:
    ```json
    {
      "status": "success",
      "message": "Hủy đơn hàng thành công.",
      "data": { /* Thông tin đơn hàng đã được cập nhật với status 'Đã hủy' */ }
    }
    ```
*   **Error Responses**:
    *   `400 Bad Request`: Đơn hàng không thể hủy (vd: đã hoàn thành).
    *   `401 Unauthorized`: Chưa đăng nhập.
    *   `403 Forbidden`: Không phải chủ đơn hàng và không phải Admin.
    *   `404 Not Found`: Không tìm thấy đơn hàng.
    *   `500 Internal Server Error`.
